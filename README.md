# UI Review Agent

URL이나 이미지에서 UI의 정보 계층, 가독성, 접근성을 검토하는 셀프호스팅 도구입니다. 리뷰 근거와 결과는 자신의 서버에 저장되며, 브라우저 대시보드에서 확인할 수 있습니다. Codex를 쓰는 경우 선택 기능인 `$ui-review` 스킬로도 요청하고 조회할 수 있습니다.

- URL 리뷰는 Chromium에서 화면을 캡처하고 DOM·접근성 정보를 수집합니다. 라이트·다크 모드를 함께 검사하거나, 제품의 그룹 정렬 기준을 지정할 수 있습니다.
- 이미지 리뷰는 PNG·JPEG·WebP를 받습니다. 한 작업에 화면을 최대 10개까지 묶을 수 있으며, 각 화면은 독립적으로 평가합니다.
- 대시보드에서 프로젝트와 화면별 검토 이력을 관리합니다. 저장된 화면의 선택 영역을 다시 질문하거나, URL 검토에서 필터 선택 같은 제한된 동작을 이어갈 수 있습니다.
- Codex 스킬 연동은 선택 기능입니다. Codex 없이 대시보드만으로 모든 리뷰를 시작하고 결과를 볼 수 있습니다. 스킬을 연결하면 MCP를 통해 작업을 접수하고 상태와 보고서를 조회합니다. 서버와 Codex가 다른 컴퓨터에 있어도 SSH로 연결할 수 있습니다.

## 시작하기

Node.js 22.12 이상과 pnpm 11.10.0이 필요합니다. pnpm이 없거나 버전이 다르면 `corepack enable`을 실행하세요. 저장소의 `package.json`(`packageManager`)에 적힌 pnpm 11.10.0이 자동으로 사용됩니다. 아래 명령은 소스 디렉터리에서 실행하세요.

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium
pnpm run viewer --host 127.0.0.1
```

Linux에서 Chromium 실행에 필요한 시스템 라이브러리가 없다면 두 번째 줄 대신 `pnpm exec playwright install --with-deps chromium`을 사용하세요. 이 명령은 시스템 패키지를 설치하므로 관리자 권한(sudo)이 필요할 수 있습니다.

서버의 기본 포트는 4317입니다. `--host 127.0.0.1`로 실행하면 이 컴퓨터에서만 [대시보드](http://127.0.0.1:4317)에 접속할 수 있습니다. 다른 기기나 원격 서버에서 접속하려면 `--host 0.0.0.0`을 쓰되, 대시보드에는 로그인이 없으므로 인증 없이 인터넷에 노출하지 마세요. 방화벽, VPN, SSH 포워딩 등으로 접속할 수 있는 사용자를 제한하세요. `--host`를 생략하면 `0.0.0.0`으로 실행됩니다. 포트는 `--port`로 바꿀 수 있습니다.

대시보드의 **설정**에서 평가자를 선택합니다. 처음 쓴다면 OpenAI 호환 API가 가장 간단합니다. 기본 평가자를 **OpenAI Compatible API**로 고르고 **API 기본 URL**(예: `https://api.openai.com/v1`), **API 키**, 이미지 입력을 지원하는 **모델 ID**를 입력해 저장하세요. API 형식은 기본값인 Chat Completions로 시작할 수 있습니다. 입력한 키는 서버의 데이터 디렉터리에 평문 파일로 저장되므로 [셀프호스팅 안내](docs/self-hosting.md#대시보드-열기와-평가자-설정)를 확인하세요. Codex CLI, Claude Code CLI, Antigravity CLI를 쓰려면 서버 실행 계정에 설치하고 로그인해야 합니다.

## 리뷰 시작하기

대시보드의 **리뷰 프로젝트 → 새 프로젝트 → 새 UI 검토**에서 URL이나 이미지를 추가합니다. Codex 스킬을 연결했다면 새 세션에서 `$ui-review`와 함께 화면과 확인할 목적을 알려주세요. 수정 후 새 검토본을 추가하면 이전 결과와 근거가 남습니다.

로그인 후의 URL 화면을 검토하려면 대시보드의 **로그인 정보 입력**에서 이번 실행에 사용할 ID·비밀번호나 일회용 코드를 입력합니다. 최초·추가 검토 모두 로그인 없이 진행할 수 있습니다. 여러 단계의 인증이 필요한 화면은 수동 로그인 CLI로 캡처하거나 비식별 이미지를 사용할 수 있습니다.

보고서를 읽을 때는 지적 사항과 함께 캡처, 관찰 근거, 검사 범위를 확인하세요. 여러 화면을 묶어도 화면 사이의 흐름이나 이전 문제의 해결 여부는 각 근거를 보며 확인해야 합니다. 이미지 리뷰는 정지 화면을 평가합니다. AI 평가 시 화면과 관찰 정보가 설정한 평가자에 전달됩니다.
